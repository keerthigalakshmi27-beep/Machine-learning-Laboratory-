How to Compile & Run the Project

Complete step-by-step instructions for Windows Command Prompt, PowerShell, or any IDE

STEP 1

Verify Python & Install Dependencies

Open Windows PowerShell or Command Prompt, navigate to the project directory, and install the required machine learning and web server packages:

python -m pip install -r requirements.txt

Packages installed: flask, pillow, numpy, scikit-learn, scipy.

STEP 2

Generate Medical Sample Images (Optional)

To generate the high-resolution clinical ECG traces and cardiac scans used by the demo:

python generate_sample_images.py
STEP 3

Train the Machine Learning Models

Train Random Forest, SVM, KNN, and Decision Tree on the cardiovascular dataset and evaluate metrics:

python train_model.py

Generates models/best_heart_model.pkl and computes 99%+ test accuracy.

STEP 4

Run Test Prediction from Command Line

To test prediction from terminal without a browser:

python test_predict.py

Or specify a custom image file:

python test_predict.py --image path/to/your/image.png
STEP 5

Launch the One-Frame Web Application

Launch the Flask server to open the interactive dashboard:

python app.py

Then open your browser and navigate to: http://127.0.0.1:5000

Project File Architecture

app.py Flask server, REST API endpoints, and live code execution controller.
preprocess.py Grayscale, Gaussian/Median filtering, CLAHE contrast equalization, thresholding, edge detection.
feature_extraction.py GLCM texture matrix (contrast, homogeneity, energy, correlation), statistical moments, cardiac wave metrics.
train_model.py Random Forest, SVM, KNN, Decision Tree training, scaling, confusion matrix, ROC-AUC calculation.
test_predict.py Command-line execution script for batch testing.
generate_sample_images.py High-resolution ECG trace and cardiac silhouette generator for 5 target classes.
